# Акції — що зробити після заливки в main

Цей коміт додає ручне додавання акцій з автопідтягуванням поточної ціни
через Finnhub. Код у git — це лише половина; Supabase (Edge Function)
потрібно оновити **окремо й вручну**. Без цього кроку застосунок збереться
й запуститься, форма додавання акції теж працюватиме — але кнопка синку
цін у шапці вкладки "Акції" буде падати з помилкою.

## 1. Міграції БД

**Не потрібні.** Таблиця `investments` вже має всі потрібні колонки
(`type IN (..., 'stock', ...)`, `ticker_symbol`, `purchase_price`/
`current_price` як `NUMERIC`) — все це з'явилось ще в міграціях
`002_investments.sql`/`009_crypto.sql`/`011_crypto_price_precision.sql`
для крипти, і генерично підходить для акцій. Нових таблиць/колонок акції
не додають.

## 2. Отримати ключ Finnhub

1. Зареєструватись на https://finnhub.io/register (безкоштовно).
2. Dashboard → API Key — скопіювати ключ.
3. Безкоштовний план: 60 запитів/хвилину — цілком достатньо (кожна
   синхронізація робить по одному запиту на КОЖЕН унікальний тікер акцій
   користувача, послідовно).

## 3. Секрет Edge Function

Supabase Dashboard → Edge Functions → Secrets → додати:
```
FINNHUB_API_KEY = <твій ключ>
```
Це **один спільний ключ на весь застосунок** (не за користувача, на
відміну від Binance) — Finnhub API-ключ не дає доступу до нічого
персонального, лише до публічних котирувань, тому зберігати кожному
користувачу свій ключ у Vault нема сенсу. Захист від зловживання чужою
квотою — `verify_jwt = true` (нижче): викликати функцію може лише
залогінений користувач застосунку.

## 4. Деплой Edge Function

```bash
cd finance-app
supabase login          # якщо ще не логінився
supabase link --project-ref wkjbafbaaoasuehohedf
supabase functions deploy stock-price-sync
```

`supabase/config.toml` уже в репо з `[functions.stock-price-sync]` і
`verify_jwt = true` — деплой підхопить це сам.

## 5. Як перевірити, що працює

1. Застосунок → Акції → "+" → створити акцію з тікером (напр. `AAPL`) і
   будь-якою поточною ціною вручну.
2. Вкладка "Акції" → кнопка синку в шапці (іконка RefreshCw) → крутиться,
   потім поточна ціна акції має оновитись на реальну з ринку.
3. Якщо не спрацювало — Supabase Dashboard → Edge Functions → Logs →
   `stock-price-sync`, шукати конкретну помилку (найчастіше — не
   виставлений `FINNHUB_API_KEY`, або тікер введено з помилкою/невірний
   формат для американського ринку, напр. "APPLE" замість "AAPL").

## 6. Обмеження поточної реалізації

- Тікер — рядок, який вводить користувач вручну (без автодоповнення/
  пошуку по назві компанії) — має бути валідним Finnhub-тікером (для
  американських акцій зазвичай просто біржовий тікер, напр. `AAPL`,
  `MSFT`, `TSLA`).
- "Вільні кошти" (готівка на рахунку, ще не інвестована) зберігаються
  **лише локально в браузері** (localStorage), НЕ синхронізуються між
  пристроями — свідомий компроміс заради простоти (щоб не додавати нову
  синхронізовану таблицю заради одного числа). Якщо знадобиться крос-девайс
  синк — див. коментар на початку `src/lib/settings/free-cash.ts`.
